# Naming rules

How "Nodpack for Twenty" may be named and described in public (npm, the Twenty marketplace, this repo's README). Not legal advice.

| Do | Don't |
|---|---|
| Call the app **Nodpack for Twenty**: our name first, "for Twenty" after a referring word, in plain text. | Use "Twenty" first or alone in the name, a logo, a domain or a handle. |
| Use Nodpack's own logo (`public/logo.svg`). | Use Twenty's logo, colours or look-alike styling. |
| Say what it does: "sets up the objects and views the Nodpack mobile app needs in your Twenty workspace". | Say "official", "partner", "certified", "endorsed" or "Vetted". Twenty's Vetted label covers only apps Twenty maintains. |
| Include the disclaimer: "Nodpack is an independent product of Protomated. It is not affiliated with or endorsed by Twenty." | Imply the app comes from Twenty ("the Twenty app", "Twenty Mobile", "native to Twenty"). |
| Use the `twenty-app` npm keyword; it is a tag Twenty requires for listing, not a name. | Put Twenty's or any other company's mark in the package scope, publisher name or bundle identifiers. |
